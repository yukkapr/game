# game
Cyber Escape
1. Общая идея и сюжет
Классический двухмерный Top-Down шутер в неоновом/киберпанк стиле. Игрок управляет персонажем (Оператором), который оказался заперт в замкнутом цифровом пространстве. Главная цель — уничтожить автономное ядро системы безопасности (Главного дрона) для совершения побега.
2. Игровой процесс (State Machine)
• Главное меню: Стартовый экран приложения с кнопками инициализации игрового процесса (Начать игру) и закрытия окна (Exit).
• Вводная катсцена: Сюжетный пролог длительностью 20 секунд (визуализация предыстории), реализующий функцию пропуска по нажатию клавиши Space.
• Игровая сессия (Бой): Активная фаза выживания на замкнутой арене. На фоне играет динамический саундтрек.
• Финал игры:
	• Экран победы (выводится при обнулении HP дрона): «You win, but Drun dead :/» (прим.: Drun в концепте можно описать как имя погибшего напарника по сюжету катсцены).
	• Экран поражения (при коллизии с дроном): «Game Over: You Died!».
3. Управление в игре
• W, A, S, D — перемещение персонажа по осям X и Y.
• Space (Пробел) — одиночный выстрел снарядом.
• Стрелки направления + Space — стрельба вектором в 8 направлениях (включая диагональные траектории).
• Esc — мгновенный выход из приложения (доступно на любом этапе).
4. Правила и механика боевой фазы
• Условия победы: Главный противник обладает запасом прочности в 100 HP. Каждое зарегистрированное попадание снаряда уменьшает прочность на 1 единицу. Текущий уровень прочности отображается в виде динамического UI-компонента (HealthBar) над противником.
• Условия поражения: Пересечение хитбоксов (коллизия) игрока и движущегося противника приводит к мгновенной смерти игрока.
• Поведение ИИ: Противник непрерывно перемещается по экрану, отскакивая от границ игрового окна по законам зеркального отражения векторов скорости.
